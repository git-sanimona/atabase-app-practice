# database-app-practice

## 概要

COACHTECH 教材 Tutorial 9-3「データベース操作ハンズオン演習」で作成した成果物です。
商品管理システムのデータベースを構築して商品一覧ページを作りました。

## 使用技術

- PHP 8.x
- Laravel 10.x
- MySQL
- マイグレーション、シーダー
- GitHub

## 学んだこと

- マイグレーションファイルを作成してテーブルして各カラムを定義しました。
- Seederでダミーデータを作成する仕方を学びました。
- sail artisan tinkerコマンドの使い方を勉強しました。
